### 2. 장단 음원 (우선순위 중간)
✅ 국립국악원 소리북 녹음 6종을 넣었습니다(`drum-*.wav`).

### 3. 직접 제작할 창작 소리 (검증 후 결정)
- 여러 이야기에서 함께 쓸 수 있는 **창작 후렴** 2~3개(예: "얼씨구나 좋을시고…" 결말 후렴) — 장단별 녹음
- 대표 장면 1개의 새 사설을 직접 녹음 → 지금의 「실제 녹음 + 새 사설 자막」 방식과 비교 청취하여 채택 여부 결정
- 녹음 시 표기: 「창작 판소리(직접 녹음)」로 원작 음원과 구분

### 4. 검토 자료
- 장단 박 구성·대목별 장단: 국립국악원 국악사전, 판소리 관련 공식 자료로 확인
- 판본(바디)에 따라 다른 경우 화면 문구에 "판본에 따라 다를 수 있음" 유지

### 5. 선택 사항
- 발표용 짧은 시연 영상(인터넷이 불안할 때 대비)
- 앱 아이콘 고해상도 PNG(홈 화면 추가용)
